## 验收清单（一口气）

1. **侧栏 tab**：文件 / 标签 / 书签 / 概念图 / 助手 / Git  
2. **历史**：搜索与恢复/导出/删除为中文  
3. **对话内查找**：占位「在对话中查找…」；无结果/区分大小写中文  
4. **书签 / 标签 / 概念图**：筛选框与空态中文  
5. **设置**：左侧分类中文；AI 提供商「已连接 / 未配置」等  
6. **终端**：空态与查找/右键中文  
7. **Vault 切换器**：打开库 / 设置等入口中文  
8. **命令面板**：占位中文；快捷键设置里主要动作名中文
